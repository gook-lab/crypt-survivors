How to wire it up

1. spritesheet.png과 atlas.json을 game/src/assets/에 복사.

2. renderer.js의 circleTexture()를 Pixi Texture.from(spritesheet).frame 캐시로 교체. 엔티티에 type 필드 두고 SPRITE_OF[type]로 클립 매핑.

3. 적 스폰 시 walker → walker_walk 등. 보스는 boss_idle / boss_vampire / boss_skeleton_king / boss_demon.

4. 픽업/투사체도 동일. fx_hit·fx_impact_*는 hit 이벤트에서 1회 재생.
