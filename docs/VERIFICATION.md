# Crypt Survivors 검증 방법

게임 규칙의 회귀는 Vitest로 확인하고, 난이도 변화는 시드 기반 헤드리스 하네스로 비교합니다. 실제 조작감과 공격 예고의 가독성은 브라우저 플레이로 별도 확인합니다.

## 자동 검증

```bash
npm test
```

테스트는 공간 해시 충돌 후보, 무기·진화 규칙, 공격 예고와 판정 시점, 세이브 마이그레이션처럼 입력과 결과를 고정할 수 있는 규칙을 다룹니다.

## 밸런스 비교

```bash
node scripts/balance.js 24
```

인수는 실행할 시드 수입니다. 기본값은 5이며, 변경 전후를 비교할 때에는 24개 이상을 권장합니다. 하네스는 10분 동안 카이팅 AI를 실행하고 생존 여부, 4분 이전 사망, 중앙값, 런당 골드 분포를 출력합니다.

### 비교 절차

1. 변경 전 커밋에서 같은 시드 수로 기준 결과를 저장합니다.
2. 밸런스 값을 한 종류만 변경합니다.
3. 같은 명령을 다시 실행해 생존율과 조기 사망 구간을 비교합니다.
4. 차이가 큰 시드는 브라우저에서 직접 플레이합니다.

고정 타임스텝과 용도별 RNG 스트림을 사용하므로 한 값을 바꿀 때 무관한 난수가 함께 바뀌는 범위를 줄였습니다.

## 브라우저 확인

```bash
npm run dev
```

다음 항목은 수치만으로 판단하지 않습니다.

- 보스 공격 예고가 판정 전에 충분히 보이는지
- 많은 적이 겹쳐도 이동 방향과 피격 원인을 알아볼 수 있는지
- 프레임 저하가 발생해도 시뮬레이션 속도가 달라지지 않는지
- 이전 버전의 세이브로 시작할 수 있는지

## 해석할 때 주의할 점

헤드리스 AI는 실제 바이옴의 장애물 회피와 모든 조작을 재현하지 않습니다. 결과는 난이도 급변과 회귀 후보를 찾는 근거이며, 플레이 감각을 대신하는 합격 기준은 아닙니다.
